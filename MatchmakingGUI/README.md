# MatchmakingGUI

Simulador de servidor de emparejamiento multijugador con interfaz gráfica en Java.

## Características
- Gestión de perfiles de usuario con tabla hash (máx. 2 colisiones por bucket)
- Inicio/cierre de sesión
- Emparejamiento por ELO y MMR oculto
- Gestión de sesiones activas
- Interfaz gráfica (Swing)
